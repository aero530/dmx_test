    * Addresses used
    * Lighting mode
* ArtNet Config
    * IP address
    * Misc settings / info
* SmartLED
    * LED Type
    * LED Count
    * Group size (between 1 and LED Count)
    * Interleaving (on / off)
    * Addresses used (output)
* PWM
    * Mode 3 channel / 4 channel
